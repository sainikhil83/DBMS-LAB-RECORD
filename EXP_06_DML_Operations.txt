DBMS MODEL LAB - EXPERIMENT 6
INSERT, DELETE, MODIFY, ALTER, UPDATE AND VIEW RECORDS

AIM:
To perform INSERT, DELETE, MODIFY, ALTER, UPDATE and VIEW operations.

ALGORITHM:
1. Create a STUDENT table.
2. Insert three records.
3. Update a record.
4. Delete a record and alter the table.
5. Display the records.

PROGRAM:
CREATE TABLE STUDENT
(
 ROLLNO NUMBER(3),
 NAME VARCHAR2(20),
 MARKS NUMBER(3)
);

INSERT INTO STUDENT VALUES (101,'RAVI',85);
INSERT INTO STUDENT VALUES (102,'RAJU',75);
INSERT INTO STUDENT VALUES (103,'SITA',90);

SELECT * FROM STUDENT;

UPDATE STUDENT SET MARKS=80 WHERE ROLLNO=102;

DELETE FROM STUDENT WHERE ROLLNO=103;

ALTER TABLE STUDENT ADD AGE NUMBER(2);

SELECT * FROM STUDENT;

RESULT:
INSERT, DELETE, MODIFY, ALTER, UPDATE and VIEW operations were performed successfully.
