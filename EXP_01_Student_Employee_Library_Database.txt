DBMS MODEL LAB - EXPERIMENT 1
Creation of Database and SQL Queries

1(a) STUDENT DATABASE
AIM: To create a student database and retrieve information.
SQL:
CREATE TABLE STUDENT(SID NUMBER(3), NAME VARCHAR2(20), MARKS NUMBER(3));
INSERT INTO STUDENT VALUES (101,'RAVI',85);
INSERT INTO STUDENT VALUES (102,'RAJU',75);
INSERT INTO STUDENT VALUES (103,'SITA',90);
SELECT * FROM STUDENT;
RESULT: Student database created and records retrieved successfully.
